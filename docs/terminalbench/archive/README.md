# Terminal-Bench Migration Archive

These files document the SkillOpt → Terminal-Bench v2.1 migration,
protocol-design process, and local validation history.

They are retained for provenance and debugging, but are not required
for running the delivered Terminal-Bench workflow.

For server deployment and formal evaluation, use:

- `../SERVER_RUNBOOK.md`
- `../CONFIGURATION.md`

Archived documents may contain historical local-machine paths or
commands. They must not be treated as portable server deployment
instructions.
